📌 Задание: Создать форк проекта и клонировать его в новую локальную репозиторию
Исходный проект:
`https://github.com/RooterAI/UP05EDU001`

🔧 Шаги выполнения:
Шаг 1. Создайте форк репозитория на GitHub
Откройте в браузере:
https://github.com/RooterAI/UP05EDU001
В правом верхнем углу нажмите зелёную кнопку Fork.
Выберите свой аккаунт GitHub (если у вас несколько организаций).
Дождитесь завершения — вы будете перенаправлены в вашу копию репозитория:
`https://github.com/ВАШ_ЛОГИН/UP05EDU001`
⚠️ На этом этапе локальный компьютер не используется — всё делается в браузере. 

Шаг 2. Клонируйте ваш форк на локальную машину
Откройте терминал (в VS Code, Git Bash или системной консоли).
Выполните команду (замените ВАШ_ЛОГИН на ваш GitHub username):



`git clone https://github.com/ВАШ_ЛОГИН/UP05EDU001.git`
Перейдите в папку проекта:



cd UP05EDU001
Теперь у вас есть локальная копия форка — это и есть «новая локальная репозитория». 

Шаг 3. (Опционально) Настройте upstream для синхронизации с оригиналом
Если в будущем понадобится получать обновления из исходного репозитория:




`git remote add upstream https://github.com/RooterAI/UP05EDU001.git`
Проверить удалённые репозитории:




`git remote -v`
✅ Результат:
У вас есть форк проекта в вашем аккаунте на GitHub.
Полная копия этого форка хранится локально на вашем компьютере.
Вы готовы вносить изменения, создавать ветки, коммитить и делать Pull Request.
