📝 Задание: Создание форка проекта и его клонирование в новую локальную репозиторию
🎯 Цель задания
Освоить профессиональную практику работы с открытыми проектами:
— научиться создавать форк чужого репозитория на GitHub,
— затем клонировать этот форк на локальный компьютер,
— подготовить рабочее окружение для дальнейшей разработки в команде.

🔗 Исходный проект
Оригинальный репозиторий для форка:
👉 https://github.com/RooterAI/UP05EDU001

🔧 Пошаговая инструкция выполнения
Шаг 1. Авторизация на GitHub
Откройте браузер и перейдите на сайт https://github.com .
Убедитесь, что вы авторизованы под своим учебным или личным аккаунтом.
Если у вас ещё нет аккаунта — зарегистрируйтесь, как указано в методичке:
Имя пользователя (Username) должно быть профессиональным (например, ivan-petrov-dev, а не cool_gamer_99).
Подтвердите email.
Выберите бесплатный тариф (Free).
Проверьте, что вы видите своё имя или аватар в правом верхнем углу GitHub.
Шаг 2. Создание форка (Fork)
Перейдите по ссылке на исходный репозиторий:
--https://github.com/RooterAI/UP05EDU001
В правом верхнем углу страницы найдите зелёную кнопку с надписью Fork.
Нажмите на неё.
GitHub спросит: «Where should we fork this repository?» — выберите свой личный аккаунт (не организацию, если вы не уверены).
Подождите несколько секунд — вас перенаправит на страницу нового репозитория вида:


--https://github.com/ВАШ_ЛОГИН/UP05EDU001
Это и есть ваш форк — полная копия оригинального проекта, но теперь он принадлежит вам.
⚠️ Важно: форк создаётся только через веб-интерфейс GitHub. Команды типа git fork не существуют — это не операция Git, а функция платформы GitHub. 

Шаг 3. Клонирование форка на локальный компьютер
Теперь нужно скопировать ваш форк с GitHub на свой ПК.

Вариант A: Через терминал (рекомендуется для обучения)
Откройте терминал (в Windows — PowerShell или Git Bash; в VS Code — Terminal → New Terminal).
Перейдите в папку, где хотите хранить проект (например, cd ~/Documents или cd ~/Desktop).
Скопируйте HTTPS-ссылку на ваш форк:
На странице вашего форка (https://github.com/ВАШ_ЛОГИН/UP05EDU001) нажмите зелёную кнопку Code.
Выберите вкладку HTTPS и скопируйте URL (он выглядит так: https://github.com/ВАШ_ЛОГИН/UP05EDU001.git).
В терминале выполните команду:
bash


--git clone https://github.com/ВАШ_ЛОГИН/UP05EDU001.git
Перейдите в созданную папку:
bash


--cd UP05EDU001
Вариант B: Через VS Code (графически)
Откройте VS Code.
Нажмите Ctrl + Shift + P (или Cmd + Shift + P на Mac) → введите Git: Clone.
Вставьте URL вашего форка:


--https://github.com/ВАШ_ЛОГИН/UP05EDU001.git
Выберите папку на компьютере для сохранения проекта.
Дождитесь завершения клонирования.
Шаг 4. Проверка и настройка локального репозитория
Убедитесь, что удалённый репозиторий (origin) указывает на ваш форк, а не на оригинал:
bash


--git remote -v
Вывод должен содержать:


--origin  https://github.com/ВАШ_ЛОГИН/UP05EDU001.git (fetch)
--origin  https://github.com/ВАШ_ЛОГИН/UP05EDU001.git (push)
(Опционально, но рекомендуется) Настройте Git, если ещё не сделали:
bash


--git config --global user.name "Ваше Имя"
--git config --global user.email "ваша@почта.github"
Шаг 5. Подготовка к работе
Теперь у вас есть:

Форк на GitHub — ваша "удалённая" копия проекта, куда вы будете отправлять изменения.
Локальная копия — рабочая директория на вашем компьютере, где вы можете редактировать код.
Вы можете:

Создавать новые ветки: git checkout -b my-feature
Вносить изменения, коммитить и отправлять их в ваш форк:
bash


--git add .
--git commit -m "Feat: add new functionality"
--git push origin my-feature
В будущем — делать Pull Request в оригинальный репозиторий (если это требуется).

У вас есть форк репозитория UP05EDU001 в вашем аккаунте на GitHub.
На вашем компьютере создана локальная копия этого форка.
Вы можете свободно редактировать файлы, делать коммиты и отправлять изменения обратно в GitHub.
Рабочее окружение готово к командной разработке по сценарию GitHub Flow.
💡 Советы
Не редактируйте напрямую ветку main — всегда работайте в feature-ветках.
Если вы делаете форк для учебного задания, уточните у преподавателя: нужно ли делать Pull Request в оригинальный репозиторий или достаточно просто иметь форк + локальные изменения.
Для синхронизации с оригинальным проектом (если он обновляется), можно добавить upstream:
bash



--git remote add upstream https://github.com/RooterAI/UP05EDU001.git
